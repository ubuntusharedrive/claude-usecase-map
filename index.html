Operating principles

  • Default to Sonnet 4.6 at High. Escalate to Opus only for genuinely hard, high-stakes, or long-horizon tasks.
  • Effort before model. If a Sonnet answer feels shallow, bump effort before reaching for Opus — usually enough, far cheaper.
  • Thinking on = verifiability. Use it when you want to check the reasoning, not just get an answer.
  • Lighter = more headroom. Lots of small tasks? Low/Med + Haiku/Sonnet keeps you well under your limits.

Refreshing the map

Claude's models, effort defaults, and your own habits drift over time. A quick monthly refresh keeps this reference honest. The whole thing takes under a minute.

The routine

  1. When the date badge turns orange (or the check-up dot isn't green), it's time.
  2. Copy the prompt below and paste it into a Claude chat.
  3. Claude returns an updated HTML file — download it (the filename carries the new version + date).
  4. Replace the old file, or if you host it on GitHub Pages, save it as index.html and push.
  5. Back here, hit "Mark checked today" to reset the clock.

Full refresh prompt

Refresh "The Claude Usecase Map" (my Claude model + effort reference, currently v2.2). Please: (1) check Anthropic's current Claude.ai model lineup and the effort/thinking settings against the official docs and update anything that changed — new or retired models, changed defaults, renamed effort levels; (2) keep the same single-file HTML design, the Cards/Table views, the hover tooltips, the age-tinted date badge, and this refresh sub-page; (3) fold in any new recurring tasks I mention, and re-balance the model/effort/cost columns if my real usage has shown a row to be off; (4) set today's date as the new build date and bump the version number, and name the download file "The Claude Usecase Map vX.x YYYY-MM-DD.html". Then give me the updated file to download.

What to verify

  • Model lineup still current? (new versions added, old ones retired)
  • Effort defaults and naming unchanged?
  • Any tasks you keep doing that deserve their own row?
  • Any row where your real usage disagrees with the suggested setting?
