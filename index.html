    Refreshing the map

    Claude's models, settings, and your own habits drift over time. A quick monthly refresh — anchored on Anthropic's own docs — keeps this honest. Under a minute.

    The routine

    1. When the date badge turns orange (or the check-up dot isn't green), it's time. Anthropic ships often — a month is a long time here.
    2. Copy the prompt below and paste it into a Claude chat.
    3. Claude checks the docs, returns an updated file — download it.
    4. Replace the old file — for GitHub Pages, save as index.html and push (keep the versioned copy alongside it).
    5. Back here, hit "Mark checked today" to reset the clock.
