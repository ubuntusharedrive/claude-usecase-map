    Refreshing the map

    Claude's models, settings, and your own habits drift over time. A quick monthly refresh — anchored on Anthropic's own docs — keeps this honest. Under a minute.

    The routine

    1. When the date badge turns orange (or the check-up dot isn't green), it's time.
    2. Copy the prompt below and paste it into a Claude chat.
    3. Claude checks the docs, returns an updated file — download it.
    4. Replace the old file, or if you host on GitHub Pages, save as index.html and push.
    5. Back here, hit "Mark checked today" to reset the clock.

    Full refresh prompt

    Refresh "The Claude Usecase Map" (my Claude model/effort/usecase reference, currently v3.0). It covers three surfaces: Claude AI (chat), Claude Code, and Claude Cowork. Please: (1) verify everything against Anthropic's official docs — support.claude.com, code.claude.com/docs, platform.claude.com/docs, and anthropic.com/news — and update anything that changed: model lineup, effort levels and defaults, Claude Code permission modes, Cowork connectors/methods, and any new surface worth adding as a tab; (2) keep the single-file HTML design, the themed flavour selector, the per-tab schemas (AI: model·effort·thinking·cost; Code: model·effort·mode; Cowork: tools·method), the click-to-open examples + prompts, the favicon, the age-tinted date badge, and this refresh sub-page; (3) fold in any new recurring tasks I mention with their own example + prompt; (4) set today's date as the new build date and bump the version, naming the file "The Claude Usecase Map vX.x YYYY-MM-DD.html". Then give me the updated file to download.

    Trusted sources to check

    • Anthropic Help Center — support.claude.com
    • Claude Code docs — code.claude.com/docs
    • Claude API / Platform docs — platform.claude.com/docs
    • Anthropic release notes & news — anthropic.com/news

    Treat the official docs as the source of truth; community guides are fine for cross-checking but verify before trusting.
